# HoMny

**HoMny (Manajemen Uang Kos)** — Aplikasi pengatur keuangan mingguan anak kos dengan konsep *offline-first* dan *bebas pusing catat harian*.

## Fitur Utama

1. **Sisa Jatah Jajan Bebas (Hero Metric)**:
   - Langsung tahu berapa uang yang aman dipakai tanpa perlu mencatat setiap pengeluaran kecil harian.
   - Pemasukan Mingguan - Kebutuhan Terkunci - Tabungan Terkunci = Jatah Jajan Bebas.

2. **Ringkasan Dana Terkunci**:
   - Memisahkan dana kebutuhan wajib kos (makan pokok, galon, laundry, dll.) dan tabungan yang diamankan di awal minggu.

3. **Checklist Kebutuhan Terkunci**:
   - Tracking kebutuhan wajib yang sudah atau belum dibayar.

4. **Pikirin Dulu (Impulse Wishlist & Filter Kesenangan Sementara)**:
   - Mencegah *lapar mata* dengan sistem penahan belanja impulsif dan evaluasi kesenangan sesaat.

5. **Offline-First & Privasi Terjamin**:
   - Semua data tersimpan aman secara lokal di perangkat tanpa perlu koneksi internet.
